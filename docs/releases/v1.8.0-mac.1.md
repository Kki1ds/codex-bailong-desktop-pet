# macOS 1.8.0-mac.1

基于上游 [v1.8.0](https://github.com/Wunsch2048/codex-bailong-desktop-pet/releases/tag/v1.8.0)（`cb130091`）和发布文档提交 `752f0893`。构建源码为 `cb06266d15fe6c7de3b92c81cfe2b8912922ba93`。验收于 2026-11-18 在 M1 Pro、macOS 27.2.1、Python 3.12.15、PySide6 6.9.2 上进行。

2026-11-18 公开为 [macOS 社区预发布](https://github.com/Kki1ds/codex-bailong-desktop-pet/releases/tag/v1.8.0-mac.1)。

## 变化

- **卡片与窗口。** 正常和大卡片改用双栏布局，数据面板随卡片展开和收起。人物和卡片可分别调大小，也可按比例联动。支持置顶、正常和置底，以及仅在 Codex 前台时显示。
- **图表与历史。** 日报和 24 小时图按小时显示实际输出速率，长回合可提前看到已有采样。模型、额度和成本可按日历查看，日报可直接打开对应日期的成本。周额度样本不足时先显示「观察中」。
- **聊天与任务状态。** 聊天页新增统一的「聊天设置」入口。会话卡补充了向其他聊天发消息、等待协作和查看图片等状态。
- **人物素材。** 素材页保留可续传的下载进度，完整校验后再启用新素材。

## 验收结果

- **源码通过。** 97 组、1118 项自动回归无失败，含平台跳过。测试目录隔离，测试夹具原先的递归清理改用保留目录，Windows 原生测试仍由各自平台执行。编译和 Mac 改动的差异空白检查通过。
- **原生窗口通过。** 在实际 Cocoa 窗口上读回人物、卡片、日报、浮窗和过渡画布的三档层级。置底且开着鼠标穿透时，主动打开设置可获得原生键盘焦点并输入数值，关闭后回到置底。用实际 Codex、Finder 和 Chrome 核对前台切换，卡片能在两块屏幕间重新定位。Chrome 最大化时卡片保持可见，进入原生全屏后让位。注入静音完成事件后保留未读且卡片仍隐藏，退出全屏后恢复。
- **本机联动通过。** 发现已运行的 Codex、CLI、会话日志和已读状态；LaunchAgent 生成、启停及失败回退通过隔离测试。钥匙串用独立测试服务名完成读写与删除。
- **冻结包通过。** 源码和挂载镜像中的程序均打开设置页并正常退出，错误日志为空。候选保留了旧主题、人物尺寸、胶囊快捷项和分离设置，旧置顶开关正确映射为正常层。镜像包含字体、素材目录和 `cryptography`，离线 TLS 探针确认启用证书和主机名验证。
