# macOS 1.6.0-mac.1

基于上游 v1.6.0（18a9ba43a49a303fd6aa5c44347ec5a9975a91ca）及发布后首页提交 214d1534219c33cb8e8b90f2745876763457e648。经 PR #2 审核后合并到 fork main，2026-11-08 以预发布公开：[Release](https://github.com/Kki1ds/codex-bailong-desktop-pet/releases/tag/v1.6.0-mac.1)。

## 变化

同步 1.3.0 至 1.6.0 的项目成本与导出、自动 API/Credits 价表、汇率设置、实时速率和逐位数字、主题、大卡片/聊天/设置布局、贴边及四种走动、素材补齐与任务提醒修复。计价沿用上游 API 等价估算口径。

Mac 保留钥匙串、数据与资源路径、Codex Unix IPC、会话跳转、登录启动和跨 Space 适配。新增窗口避让仅读取前台应用 PID、普通窗口边界，按所在屏幕裁剪；新提示浮窗共用 Mac overlay。通用全屏期间完成提醒不抢回显示，应用内程序更新继续关闭。素材沿用上游 v1.3.0 的 35 动作完整资源。

修正价表/计价偏好的默认存储目录、旧库维护对系统路径别名的拒绝，以及原维护待办的设置冲突标题、多余未读信号连接、诊断全屏字段。

PR 审核补充修正（2026-11-08）：额度 CLI 启动失败记录改存 Mac 数据目录（原会在主目录新建 BailongEnhanced）；共享文件换行按上游统一；Codex 在任务完成后为同一 turn 补写的后台命令完成记录不再把会话重新判为执行中。最后一项为上游通用逻辑，真机现象为状态长期“忙碌”、自主走动和随机动作被跳过、状态图标持续 60 帧刷新。

## 本轮验证（2026-11-07）

环境：本机 macOS arm64、Homebrew Python 3.12.15、PySide6 6.9.2。

- `tools/check_source.py --macos`：86 个模块，946 项测试（包含显式平台跳过），所有模块成功；按模块独立进程、隔离用户目录和 Codex 目录。
- 包含价格解析与失败缓存、项目归属/成本/数据库维护、日志速率、实时数字、素材复用和取消、窗口交接、主题、Unix socket、钥匙串替身和旧设置兼容回归。新增 Mac 专项 7 项全部通过。
- Windows 安装事务、历史安装清理、PE 裁剪保留在 Windows CI，不在 Mac 执行。Windows DLL/监听 ABI 场景显式按平台跳过，不放宽生产路径安全规则。
- Cocoa 源码隔离实例使用 `--smoke-test --settings` 启动、显示设置并自动退出，退出码 0。
- 最终冻结包以隔离数据执行 Cocoa 设置页启动检查，生成 1.6.0 运行快照并自动退出，无错误输出。
- 最终仅卡片 `.app` / DMG 构建成功；构建脚本执行深度严格签名与镜像校验。候选产物位于本地 `release/macos-1.6.0-20261107-220810/`；另行复核签名及 DMG SHA-256 通过，不上传。

## PR 审核与人工验收（2026-11-08）

PR 审核补充修正后，`tools/check_source.py --macos` 为 87 个模块、959 项测试，全部成功（包含显式平台跳过）；最终提交的 Windows、Linux、macOS CI 通过。

维护者在本机真实环境验收通过：Chrome 原生/视频全屏让位（完成提醒不抢回显示，普通最大化不让位）、多屏混合缩放下拖动/贴边/分离面板、新浮窗与主题切换、减少动态效果、真实 Codex 任务/完成提醒/已读/跳转、登录启动与钥匙串授权、轻量素材下载与动作边界切换；修复忙碌卡住后，源码运行状态回到空闲，窗口模式自主走动正常触发。
