# macOS 社区预发布 1.2.1-mac.1

基于上游 v1.2.1（c725ede174f43800ee5c356d687574e762737805）。适用于 Apple Silicon；安装包仅含卡片，人物动画在设置中按需下载。

## 更新

- 合入 1.1.0 至 1.2.1 的额度周期与重启统计修复、可配置额度涨跌提醒、菜单栏额度环、按钮悬停提示、卡片连续过渡和显示缩放恢复。
- 动画缓存可在设置中更改位置：后台复制校验、等待动作边界切换，失败保留原目录；程序仍通过替换 .app 升级。
- Mac 使用“全屏应用时让位”开关。开启后，所在屏幕上的其他应用全屏时隐藏人物和面板，完成提醒保留至退出全屏后显示。旧开关偏好自动迁移；不区分视频、游戏和办公应用，不新增辅助功能权限。
- 修复新版 macOS 中 Chrome 将全屏拆成多个原生窗口导致漏检的问题；普通最大化窗口保留菜单栏区域，不触发该判断。
- 保留 Mac 数据路径、钥匙串、Codex Unix IPC、登录启动和跨桌面窗口适配；应用内 Windows 更新与安装管理继续关闭。

## 安装与校验

下载 `BailongEnhanced-1.2.1-mac.1-macos-arm64.dmg` 和同名 `.sha256`。在下载目录运行：

```bash
shasum -a 256 -c BailongEnhanced-1.2.1-mac.1-macos-arm64.dmg.sha256
```

打开 DMG，将应用拖至 Applications。升级前退出旧版，再替换应用；设置、统计和已下载素材仍保存在 `~/Library/Application Support/BailongEnhanced`。应用为 ad-hoc 签名，未公证，首次打开可能需要在系统设置的“隐私与安全性”允许打开。
